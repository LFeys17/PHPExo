# Exercice 06 - Échanger deux verres

## Objectif

Vous vous entraînez à raisonner sur l'ordre des affectations.

## Point de départ

Créez un fichier `index.php` vierge dans ce dossier.

## Consigne

Sur une table, le verre de gauche contient du jus d'orange, et le verre de droite de l'eau.

1. Le script range le contenu de chaque verre dans une variable, puis l'affiche.
2. Le script échange le contenu des deux variables, puis l'affiche à nouveau. Les contenus ne sont écrits qu'une seule fois dans le script.

## Résultat attendu

Le terminal peut afficher :

```
Avant : gauche = jus d'orange, droite = eau
Après : gauche = eau, droite = jus d'orange
```

Testez votre script avec ces contenus :

| Gauche, avant  | Droite, avant | Gauche, après | Droite, après  |
| -------------- | ------------- | ------------- | -------------- |
| `jus d'orange` | `eau`         | `eau`         | `jus d'orange` |
| `thé`          | `café`        | `café`        | `thé`          |
| `lait`         | `lait`        | `lait`        | `lait`         |

## Coup de pouce

<details>
<summary>Indice</summary>

Dans la vraie vie, pour échanger le contenu de deux verres, on a besoin d'un troisième verre.

</details>
