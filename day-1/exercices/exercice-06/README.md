# Exercice 06 - Des guillemets dans le texte

## Objectif

Vous vous entraînez à afficher un caractère qui a déjà un rôle en PHP.

## Point de départ

Créez un fichier `index.php` vierge dans ce dossier.

## Consigne

1. Le script affiche la citation du résultat attendu, guillemets compris.
2. Remplacez "Nour" par le prénom de votre binôme.

## Résultat attendu

Étape 1, le terminal affiche :

```
Nour a dit : "Le code, ça s'explique !"
```

## Coup de pouce

<details>
<summary>Indice</summary>

Vous connaissez déjà un caractère qui change le sens de la lettre placée juste après lui.
