# Exercice 03 - Ticket de caisse

## Objectif

Vous vous entraînez à écrire un script qui reproduit un affichage exact.

## Point de départ

Le fichier `index.php` ne contient que les balises PHP. À vous d'écrire la suite.

## Consigne

Une boulangerie veut imprimer ses tickets de caisse.

1. Le script affiche l'en-tête du ticket : le nom de la boulangerie, encadré par deux lignes de `=`.
2. Il affiche les trois articles achetés, un par ligne.
3. Il affiche le total, sous une ligne de `-`.
4. Il termine par une ligne vide, puis un message de remerciement.

## Résultat attendu

Le terminal affiche exactement :

```
==============================
    BOULANGERIE DU BEFFROI
==============================
1 baguette ....... 1,20 euros
2 croissants ..... 2,40 euros
1 tarte au sucre . 4,50 euros
------------------------------
TOTAL ............ 8,10 euros

Merci et à bientôt !
```

## Avant de coder

En haut de `index.php`, écrivez en commentaires les étapes de votre programme, en français.

<details>

Avancez étape par étape : codez l'en-tête, lancez, comparez avec le résultat attendu, puis passez à la suite.
