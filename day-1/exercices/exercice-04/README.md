# Exercice 04 - Fusée

## Objectif

Vous vous entraînez à dessiner avec du texte, et à désactiver des lignes de code sans les effacer.

## Point de départ

Le fichier `index.php` ne contient que les balises PHP. À vous d'écrire la suite.

## Consigne

Une fusée de la NASA se prépare au décollage.

1. Le script affiche la fusée en vol : un titre, la fusée, puis ses flammes.
2. Le moteur s'éteint : le titre devient "Au sol" et les flammes disparaissent. Aucune ligne de votre script ne doit être effacée.

## Résultat attendu

Étape 1, le terminal affiche :

```
=== Décollage ! ===
        ^
       | |
       |N|
       |A|
       |S|
       |A|
      <| |>
       ***
        *
```

Étape 2, le terminal affiche :

```
=== Au sol ===
        ^
       | |
       |N|
       |A|
       |S|
       |A|
      <| |>
```

## Avant de coder

En haut de `index.php`, écrivez en commentaires les étapes de votre programme, en français.
