# Exercice 01 - Chasse au trésor

## Objectif

Vous vous entraînez à naviguer dans des dossiers avec le terminal, et à lancer un script.

## Point de départ

Le dossier `exercice-01` contient un script `index.php` et plusieurs lieux à explorer. Chaque lieu est un dossier, avec son propre script. Un trésor se cache dans l'un d'eux.

## Consigne

Pour tout l'exercice, utilisez uniquement le terminal intégré de VSCode, jamais l'explorateur de fichiers.

1. Placez-vous dans le dossier `exercice-01`, puis lancez son script. Explorez les lieux de dossier en dossier, jusqu'au trésor.
2. Modifiez le script du trésor : il affiche en plus, sur une dernière ligne, "Trésor trouvé par :" suivi de votre prénom.
3. Revenez dans le dossier `exercice-01`. Sans en sortir, lancez le script du trésor.

## Résultat attendu

Depuis le dossier `exercice-01`, le terminal affiche le message du trésor. La dernière ligne contient votre prénom :

```
Trésor trouvé par : <votre prenom>
```

## Avant de modifier

En haut du script du trésor, écrivez en commentaire ce qu'il fait, en une phrase.
