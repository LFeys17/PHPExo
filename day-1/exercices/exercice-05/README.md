# Exercice 05 - Un cadre, une instruction

## Objectif

Vous vous entraînez à afficher plusieurs lignes avec une seule instruction.

## Point de départ

Créez un fichier `index.php` vierge dans ce dossier.

## Consigne

1. Le script affiche un cadre de bienvenue sur cinq lignes, avec une seule instruction.

## Résultat attendu

Le terminal affiche :

```
+----------------------+
|                      |
|   Bienvenue, Ada !   |
|                      |
+----------------------+
```
