# Exercice 04 - Les nombres pairs

## Objectif

Vous vous entraînez à écrire une boucle `while` et à choisir comment son compteur avance.

## Point de départ

Le fichier `index.php` contient une variable : le dernier nombre à examiner. À vous d'écrire la suite.

## Consigne

1. Le script affiche tous les nombres de 0 à `$maximum`, un par ligne.
2. Le script n'affiche plus que les nombres pairs.
3. Après la liste, le script affiche combien de nombres il a affichés : "Nombres pairs affichés : 11".

## Résultat attendu

Testez votre script avec ces valeurs de `$maximum` :

| `$maximum` | Le terminal affiche                                                                                              |
| ---------- | ---------------------------------------------------------------------------------------------------------------- |
| `20`       | `0`<br>`2`<br>`4`<br>`6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20`<br>`Nombres pairs affichés : 11` |
| `7`        | `0`<br>`2`<br>`4`<br>`6`<br>`Nombres pairs affichés : 4`                                                         |
| `1`        | `0`<br>`Nombres pairs affichés : 1`                                                                              |
| `0`        | `0`<br>`Nombres pairs affichés : 1`                                                                              |

## Avant de coder

En haut de `index.php`, écrivez en commentaires les étapes de votre programme, en français.
