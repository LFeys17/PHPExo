# Exercice 05 - La tirelire

## Objectif

Vous vous entraînez à faire grandir un total dans une boucle, sans modèle de départ.

## Point de départ

Créez un fichier `index.php` vierge dans ce dossier.

## Consigne

Noa remplit sa tirelire. Le jour 1, Noa y met 1 euro. Le jour 2, 2 euros. Le jour 3, 3 euros. Et ainsi de suite.

1. Le script affiche le total de la tirelire après un nombre de jours rangé dans une variable.
2. Le script affiche aussi le total à la fin de chaque jour.

## Résultat attendu

Pour 4 jours, le terminal peut afficher :

```
Jour 1 : 1 euros
Jour 2 : 3 euros
Jour 3 : 6 euros
Jour 4 : 10 euros
Total après 4 jours : 10 euros
```

Testez votre script avec ces nombres de jours :

| Nombre de jours | Total en euros |
| --------------- | -------------- |
| `4`             | `10`           |
| `10`            | `55`           |
| `1`             | `1`            |
| `0`             | `0`            |
| `365`           | `66795`        |

## Coup de pouce

<details>
<summary>Indice</summary>

Il faut deux variables : une qui compte les jours, une qui garde le total de la tirelire.

</details>
