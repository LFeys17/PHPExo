# Exercice 02 - Pair ou impair

## Objectif

Vous vous entraînez à utiliser le résultat d'un calcul dans une condition.

## Point de départ

Le fichier `index.php` contient un script qui affiche le reste de la division d'un nombre par 2.

## Consigne

1. Lancez le script avec 7, puis avec 8. Observez le reste affiché.
2. Au lieu du reste, le script affiche "7 est impair" ou "8 est pair", selon le nombre.
3. Vérifiez tous les cas du résultat attendu.

## Résultat attendu

Testez votre script avec ces valeurs de `$nombre` :

| `$nombre` | Le terminal affiche |
| --------- | ------------------- |
| `7`       | `7 est impair`      |
| `8`       | `8 est pair`        |
| `0`       | `0 est pair`        |
| `-7`      | `-7 est impair`     |

## Avant de modifier

En haut de `index.php`, écrivez en commentaire ce que fait le script actuel, en une ou deux phrases.
